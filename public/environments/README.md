# Local copies of the original environment presets

The four files are the same 1K Poly Haven HDRIs selected by the original drei presets, renamed to the project's existing preset IDs. The editor and automation renderer now load them locally, with the same intensity and rotation controls.

| Local file | Original asset | Primary source |
| --- | --- | --- |
| studio.hdr | Studio Small 03 | https://polyhaven.com/a/studio_small_03 |
| city.hdr | Potsdamer Platz | https://polyhaven.com/a/potsdamer_platz |
| sunset.hdr | Venice Sunset | https://polyhaven.com/a/venice_sunset |
| warehouse.hdr | Empty Warehouse 01 | https://polyhaven.com/a/empty_warehouse_01 |

Poly Haven publishes its assets under CC0: https://polyhaven.com/license . These HDR files were copied from the same pinned drei-assets revision used by the installed drei package. Exact source URLs and SHA256 checksums are in `sources.json`.
