# 相机分段与新版工作台

适用：2026-11-04 的 P1-44～52 更新。开发任务和验收状态见 [唯一工作计划](../IMPLEMENTATION_ROADMAP.md)。原人工核验记录保留，你已免除剩余逐项核验，无需重新填写整份清单。

## 手机缩放与相机移动

把手机放到画面右侧，再用滚轮或“缩放”数值缩小，手机保留当前放置位置。新规则围绕手机自身中心缩放；放大或旋转会穿过地面时才上抬，不会在缩小时自动下落。旧工程原有的位置动画保留，新缩放操作可撤销。

点击预览画面后即可用键盘控制相机，即使手机或文字仍被选中：W/S 上下平移，A/D 左右平移，↑/↓ 前进后退，←/→ 绕观察中心环绕，Shift 按住精调。画布下方会提示“相机控制中”。

选中对象后，滚轮继续缩放对象；点击空白取消选择后，滚轮调整相机远近。输入框负责输入，时间轴方向键负责关键帧/播放头，点击画面即可返回相机操作。

已有相机动画时，普通页面的相机移动是临时查看；点“返回成片镜头”恢复保存的视角。要把运动写进作品，请进入录制页。

## 添加多段相机动画

1. 把“当前时间”移到一段空白时间，点击时间轴左侧“相机运动”，再点“录制相机运动”。没有相机动画时也可直接点该行的“添加相机动画”。
2. 录制页显示本次可录区间：遇到下一段相机动画或作品末尾时自动结束。可在空档内调整开始时间，已有动画的时间不能作为新段起点。
3. 选择速度，点“开始录制”，倒计时后用鼠标及键盘控制镜头。手机、文字和屏幕视频继续播放，页面中的对象编辑锁定。
4. 点“结束录制”，检查回放后选择“采用本次录制”。本次录制成为一个独立相机段，整次采用可以一次撤销。

时间轴只显示相机动画色块，内部采样点隐藏且不能编辑。比如 1～3 秒和 6～8 秒有相机段：3～6 秒保持第一段结束时的镜头，8 秒以后保持第二段结束时的镜头。

新段默认从该时刻保存的成片视角继续。如果在准备阶段另行构图，开始时可能产生跳切，回放会提示；可以重新录制，保持原起点视角。

## 删除或重新录制一段

点击相机色块，底部显示段名和起止时间，以及“定位到开始、回放此段、重新录制此段、删除本段”。重新录制时使用该段区间，放弃保留原运动，采用只替换这一段。

删除一段不移动其他段的时间，也不修改其他段的轨迹；空出来的时间按停留规则处理。删除全部相机段后回到工程的基础构图，撤销可恢复。旧工程的完整相机轨迹显示为一个“原有相机动画”段，保留原回放。

## 视频滑块和时间轴

- 蓝色端点调整视频出现/消失，橙色端点调整播放开始/暂停。两区间仍各自独立，显示期间的播放区间外保持首帧或停止帧。
- 两端靠近时按钮上下避让，细条的时间位置不变。至少保留一帧，松开后仍能再次分别拖动两端；悬停可看精确秒数。
- 两个视频只有显示和播放区间都不冲突、端点也不会互相遮挡时，才共用一行。时间轴缩放后会重新检查间距；上下行不会改变屏幕视频的前后层级。
- 秒尺上只有一个播放头，下方竖线贯穿轨道。拖动秒尺、唯一播放头或轨道空白查看画面。对象名称卡片与零秒之间留出空隙，横向滚动时名称仍可见。
- 选中对象关键帧后，底部可用“关键帧属性”和“删除关键帧”。首关键帧保留，删除按钮会禁用；可调整其姿态，或删除整个对象。

## 文字景深

在“环境 → 画面效果”开启景深，对焦对象可以选择手机或实体文字。实体文字随三维姿态参与对焦；目标离场时使用有效固定距离，删除目标会保留当时焦距并提示重选，撤销可恢复。

贴纸文字默认清晰。在该文字设置中开启“受景深影响”，再调整“景深距离”；越接近当前焦点越清晰，远离时模糊。这是景深用的距离，不会移动贴纸、改变大小或前后层级。总景深关闭后贴纸也恢复清晰。

手机、实体文字和贴纸效果共用预览及导出流程。工程保存为版本 5，仍可打开旧版本；保存后重开保留相机段、视频、文字和景深设置。
