# AI Promo Studio — 分页面前端效果图 V2

本目录是符合新版产品需求的**可点击静态 UI 原型**，不是已有项目的功能实现。基于纯 HTML/CSS/JavaScript，离线浏览器打开 `project.html` 即可预览。

## 页面导航与拆分

1. `project.html` — 项目视频片段列表。仅负责片段浏览和打开详情，不出现录屏步骤、剪辑工具与完整时间轴。
2. `recording.html` — 片段详情与逐步录屏指导。只有录屏建议、模板效果与进入编辑器的入口。
3. `editor.html` — 轻量剪辑器。全屏聚焦预览，只有四项常用操作（替换录屏、更换模板、修改文字、调整镜头）；点击后右侧才出现对应选项。高级编辑按需进入。
4. `templates.html` — 独立模板中心。收藏功能使用本地浏览器存储演示，支持“我的收藏”过滤。

页面跳转：片段列表 → 查看详情 → 录屏指导 → 打开编辑器 → 完成编辑返回列表。导航栏可前往模板中心/收藏。

**原型限制：**演示用的手机和应用界面由 CSS 绘制，并非 GLB 渲染；按钮跳转、收藏和文字编辑是轻量交互演示；录屏上传、AI 源码分析、渲染/导出等真实业务能力需要随后接入原工程。
