# 前端信息架构与简洁编辑器规范

## 设计主张

借鉴 Dify 的**左侧工作区导航、独立详情页、清晰层级和留白**，不照搬其业务信息。用户已经明确否定了“片段列表 + 录屏步骤 + 模板推荐 + 3D 剪辑控件全放一个页面”的密集设计。

## 独立页面路由建议

```text
/workspace                         工作台
/projects                          项目列表
/projects/:projectId               项目概览/源码分析
/projects/:projectId/segments      片段列表（设计主参考图 01）
/projects/:projectId/segments/:id  片段详情和录屏指导（设计主参考图 02）
/projects/:projectId/segments/:id/edit  简洁片段编辑（设计主参考图 03）
/templates                         模板库与收藏（设计主参考图 04）
/projects/:projectId/compose       整片合成（后续独立页）
```

入口清晰：项目列表 `查看详情` → 录屏指导 `开始编辑` → 简洁编辑 `返回片段`；模板中心作为另一条导航入口。不要通过堆侧栏模拟所有页面。

## 单片段编辑页默认的四个动作

1. **替换录屏**：上传/更换/裁剪、查看录屏指导，上传后自动贴屏。
2. **更换模板**：推荐 / 收藏 / 我的模板，切换仅替换模板基线，已有录屏不丢失。
3. **修改文字**：片段标题、屏幕外文案、字幕内容及简化样式。
4. **调整镜头**：拖动设备、首尾关键帧、角度、大小、运动速度；自由入场/退场。

默认隐藏 FOV、材质粗糙度、复杂曲线、UV 细节、所有通道列表；用户主动打开专业模式才展示。两种模式必须共享同一份项目状态。用户点击设备时可以出现极少量相关浮动工具，但**不要恢复原来复杂的全常驻参数栏**。

## 状态驱动显示

- 无录屏：重点引导查看步骤、上传录屏。
- 已上传：突出预览、模板切换和基本修改。
- 点击文字：只显示文字相关设置。
- 点击 3D 模型：只显示镜头移动/旋转和关键帧快捷操作。
- 进入专业模式：允许完整时间轴、材质、灯光、相机和动画曲线。

## 模板中心和收藏

- 模板卡片有封面、适用场景、时长范围、收藏按钮和预览入口。
- “收藏”是对系统模板的关联，**不复制原模板内部资源**。
- “保存为我的模板”是用户将调整后的参数快照存为独立模板，带版本，不含录屏隐私内容。
- 刷新和跨页面后收藏、最近使用、用户模板必须持久有效；第一阶段本地数据库/IndexedDB 亦可，不必提前上云。

## 页面验收

在 1440px 左右桌面宽度上，用户看着页面应立刻知道**下一步做什么**。操作旅程：项目 → 片段 → 录屏指导 → 编辑，任何时刻有明确返回入口。不要在片段列表出现时间轴，不要让录屏步骤常驻编辑器三栏，也不要在模板中心摆出每个 Three.js 材质参数。
