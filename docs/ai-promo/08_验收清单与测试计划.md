# 可执行验收清单

以下 `- [ ]` 表示**尚需在本机/有依赖环境验证**，不是当前已通过的成果。

## P0：基础引擎

- [ ] `npm ci` / `npm test` / `npm run build` 通过（按实际子项目调整）。
- [ ] 4 个已随原仓库分发的 GLB 正常加载；不以程序生成盒体替代真实手机模型。
- [ ] MP4 录屏能显示到正确设备屏幕，方向、比例和 UV 正确。
- [ ] 手机按关键帧位置、旋转和缩放运动，重复渲染同一时刻画面一致。
- [ ] 导出 5–10 秒可播放、包含真实录屏的 3D 片段，留存成片和日志。
- [ ] 如果使用扩展工程，Playwright Worker 与 Remotion 做实测，无 npm 则明确记录未验证。

## P1：智能构图单设备

- [ ] 16:9 和 9:16 支持归一化画面定位。
- [ ] 横竖屏设备投影边界正常；相机后点 / 近平面行为已处理。
- [ ] 屏幕可读区域与文案留白可以估计、可调试。
- [ ] 从画面外进入、画面内展示、画面外退出的镜头不被自动强制拉回。

## P2：多设备

- [ ] 双手机整体移动时不无故散开。
- [ ] 三设备中央突出 + 两侧错层可实现。
- [ ] 五设备展开、收拢和错时入场可实现。
- [ ] 混合大小的手机 + 平板可通过投影尺寸协调（有合法模型资产时）。
- [ ] 允许刻意遮挡、交叉、出画；意外重叠有可见提示。
- [ ] 对整个运动片段采样，关键帧间没有明显跳变或布局崩溃。

## P3：自然语言自由度

- [ ] 10 条不同自然语言指令生成有区别的关键帧和运动阶段。
- [ ] 用户输入“慢一点、停 2 秒、向右退出”会局部修改，不会重置录屏和字幕。
- [ ] 能手工调整 AI 生成的坐标、关键帧、相机，不锁死模板。

## P4：源码与录屏指导

- [ ] 真实 ZIP 输入不会执行未知代码、不会解压路径穿越或密钥泄露。
- [ ] 功能清单能显示代码证据/待确认状态。
- [ ] 片段不是固定三段；用户可删除、修改、重新生成单片段。
- [ ] 每个片段有具体可执行的录屏步骤、停留时长和准备建议。

## P5：界面与模板

- [ ] 列表、详情、编辑、模板四个独立页面可跳转，默认简洁模式不会同时展示所有模块。
- [ ] 片段编辑主界面核心四个按钮。
- [ ] 收藏和个人模板在刷新后保留，能跨项目复用但不夹带原项目录屏。
- [ ] 片段修改后保存并重新打开数据不丢失。

## P6：最终合成

- [ ] 同一场景渲染无录屏时码错误。
- [ ] 三段成片含字幕、配乐和简单转场。
- [ ] 最终 MP4 正常播放，时长、FPS、分辨率与期望一致。
- [ ] 渲染失败有日志、状态和重试入口，不产出假的成功文件。

## 回归：不破坏原项目

- [ ] 原 Device Mockup Studio 手工编辑器仍可运行。
- [ ] 原有 LICENSE 与第三方模型来源说明仍保留。
- [ ] 新增功能优先模块化，不用未被验证的完整重构替换成熟模块。
