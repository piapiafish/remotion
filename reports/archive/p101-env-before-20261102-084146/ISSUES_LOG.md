### P1-02 修复补充

MAN-003：设备列表与选中项在同一次 store 更新中提交；撤销、重做、删除和其他替换流程按 instanceId 保持选择，不存在时回退到有效相邻项。参数面板增加临时无效选择保护，localhost bridge 替换工程也同步归零选择。本轮真实浏览器已补验原先阻塞的重做。

MAN-004：只移动新实例，按当前镜头、画幅与模型尺寸选择错开位置；复制时给所有位置关键帧加同一偏移，保留时间、缓动、插值、旋转和素材。已有设备和相机不被重新布局。连续添加/复制独立撤销，切换设备后不会把两台的参数修改合成一次撤销。

竖屏画幅中横向设备本身过宽时，保持原尺寸/镜头的放置只能尽量保证新实例可见；本轮留有实际帧供审阅，不承诺高密度场景或整段运动无碰撞。详见 [P1-02 报告](reports/current/p102-20261101/README.md)。MAN-009 的导出证据新增“双实例共享同一录屏的一秒短片”，不同录屏时序、较长片段及真实作品仍归 P1-06/P1-07/P1-09，未整体关闭。

预设保留范围外关键帧，但新的边界键会与外部键重新插值连接；范围是关键帧覆盖范围，未增加片段剪切。命名缓动显式替换 Continuous 通道的插值方式。上述行为在操作说明中公开。

MAN-006、MAN-008 保持未解决；MAN-009 新增双真实机型、两份不同录屏及不同动作的两秒样本，未关闭约 30 秒、更长片段及最终作品验收。MAN-003/004 的正式修复状态沿用 P1-02，竖屏过宽与自动避碰边界仍保留。

## 环境限制与保留的基线

本轮 Agent/API 测试 15 通过、10 项因 localhost EACCES 阻塞；Python Playwright 初始化超时后改用现有 JavaScript SDK 完成前端浏览器审查。本地路由供给的原生产构建不证明 Vite/本地 API TCP 已通过。后续在允许本地网络的环境补验；相关服务被验收流程使用时纳入 P1-09，环境阻塞不新增为产品 MAN 缺陷。

214 项前端测试、构建和 lint 退出成功（本轮 13 条 warning）；旧轮次 25 项 API 全通过及 14 条 lint warning 只代表其原始轮次。首次人工审查的中断记录仍保留在 [manual-audit.json](reports/archive/pre-20261101/evidence/manual-editor-audit-20261030/manual-audit.json)，不覆盖本轮独立场景结果。
