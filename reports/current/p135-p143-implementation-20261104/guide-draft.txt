# 新版时间轴、实体文字与相机操作

适用：2026-11-04 的 P1-35～43。打开 D 盘项目并刷新本地编辑器。原有人工核验记录保留，本页提供本批操作和复核步骤。

## 实体文字的选择、移动与地面

点击“添加实体文字”，在预览中点文字或左侧时间轴名称即可选中。蓝色框标出范围；“移动”显示 X/Y/Z 手柄，可以上下、左右及前后移动。“旋转”显示旋转手柄。右侧的水平、垂直、纵深、三轴角度和厚度可精调，操作可一次撤销，Esc 取消当前拖动。

向下移动会停在固定地面上方。字形、换行、对齐、旋转、厚度和缩放都会参与接地计算，动画中间帧也受限制。地面不会跟随某个对象移动；改变姿态后可以悬空，不会自动落下。贴纸文字仍固定在画面上，不受地面约束。实体文字目前使用内置常规字重。

## 手机围绕最初放置点缩放

手机保存自己的初始缩放点。之后移动手机不会改变该点；缩小时会向初始点靠拢，放大时会远离。手机还在初始点时，就是原地缩放。

例如初始水平位置为 0，移到 2 后，缩小到原来一半，中心水平位置变为 1。如果要精确设置最后的位置，先调整缩放，再输入位置。接地可能抬高最终垂直位置；不会移动地面。复制手机有自己新的初始点，保存重开后保持。

旧工程原画面和旧轨道在打开时保留；旧手机首次采用新缩放操作时，用首姿态作为兼容锚点，整个编辑可撤销。

## 对象底条：什么时候存在

整块对象时间区域的底层就是对象存在条。拖左右两端设置出现/消失；拖底部空余背景可整体平移动作及该对象所有视频的时间。不能把已有关键帧或片段移动到负时间。

出现时刻包含，消失时刻不包含。区间外，手机和实体文字从运行场景移除，贴纸退出画面合成，阴影、命中及对应手柄也停止。工程内仍保留对象、素材和关键帧，倒拖、扩展区间或撤销后会恢复。在右侧“对象显示时间”可以输入数值，或点击“转到显示开始”。

## 同一手机添加多个视频

选中手机，在“屏幕内容”点击“添加视频”或拖入文件。每次添加都增加一个独立片段，视频卡片可选择、替换/重新绑定或移除。相同文件会共用保存的素材字节，每段仍有独立时钟。图片作为静态屏幕内容，无活动视频时显示该图片或默认屏幕。

视频时间不重叠时自动共行；同时显示的片段上下排列，靠上的在手机屏幕前层。点击卡片“上移视频”改变层级，可撤销。“下移”可以反向调整。复杂交叠时优先保持前后顺序，再尽量合行；合行不会合并片段。

没有视频时只占一个基础条高，需要同时展示更多视频层时才增加高度。左侧对象名称有整块底色和更大的选择面积，横向滚动仍可选择。

## 蓝色和橙色两对端点

| 控件 | 改变什么 |
| --- | --- |
| 对象底条两端 | 整个对象出现和消失 |
| 视频蓝色两端 | 这段视频何时在屏幕出现和消失 |
| 橙色 ▶ / Ⅱ 两端 | 这段视频何时开始播放、何时暂停 |
| 视频条主体 | 同时平移该视频的显示和播放区间 |
| 菱形关键帧 | 对象的姿态时间，重叠时优先拖动关键帧 |

两对视频端点独立调整。显示期间，起播前保持选取的首帧，暂停后保持停止时的画面。素材提前播放完会保持末帧，有提示说明。视频不可见时，时间仍按作品计算，重新出现会到达对应画面。

例：蓝色 1～7 秒，橙色 2～5 秒，源从第 1 秒开始、1 倍速：作品 1～2 秒显示源第 1 秒；2～5 秒播放；5～7 秒定格；到 7 秒这段视频退出屏幕，手机由自己的底条控制。

选择视频，在“动画调节 · 屏幕视频”精调两个区间、源开始/结束和 0.25～4 倍速度。改速保持作品中的两个区间；“匹配素材播放长度”才会调整暂停端点。旧工程循环先保留，重新编辑双滑块后转为单次播放，可撤销。

## 关键帧继续按对象编辑

一个对象的姿态键叠在视频条上方。关键帧与视频重叠时优先移动关键帧；滑块被遮住时，可选中视频后使用精确数字调整。点菱形后用 ↑ 增加一帧、↓ 减少一帧，Shift 为十帧；方向键此时归时间轴，不操作相机。

同一时刻允许独立叠放，点击数量选择上层或下层。跨过其他关键帧不会合并，超过片尾自动延长；首姿态不能直接删除，会有说明。时间轴放大和上/下一个关键帧仍可用。

## 相机按键与录制

点击空白取消对象选择，再点击画布取得焦点：

| 按键 | 操作 |
| --- | --- |
| W / S | 上 / 下平移 |
| A / D | 左 / 右平移 |
| ↑ / ↓ | 前进 / 后退 |
| ← / → | 围绕当前场景构图中心向左 / 右环绕 |
| Shift | 按住精调 |
| 鼠标拖动 / 滚轮 | 旋转视角 / 调整远近 |

默认移动更快。录制页可选慢、标准、快三档。输入框和时间轴有焦点时不会控制相机；选中对象时滚轮继续缩放该对象。

点击“录制相机运动”进入专页，画面准备好后可开始。设置作品开始位置与速度，点击开始，倒计时三秒后手机、文字和录屏正常播放，你只控制相机。结束后回放、重新录制或采用。采用才写入工程，可一次撤销；页外普通查看不会改已有相机动画。

## 保存、导出和本批复核

新保存使用格式版本 4，包含所有视频源、片段时间/层级、缩放锚点和实体字形。当前可打开版本 1/2/3；旧程序不支持新版格式，请保留原始工程。离线重开实体文字使用包内字形；改成包里没有的新字时，需要本地内置字体。

建议依次复核：文字选中与 XYZ/触地 → 手机移开后缩放 → 一台手机添加三段视频 → 两对端点独立移动/定格 → 视频共行与上移遮挡 → 视频上拖关键帧 → 相机新按键与录制 → 保存关闭重开 → 导出短片。

运行场景移除不表示所有内存归零：工程和素材、共享模型、有界缓存及复用手柄仍保留。自动检查与具体成片证据见 [本轮报告](../reports/current/p135-p143-implementation-20261104/README.md)，字体观感、运镜手感及最终视觉由你复核。
