## 实施范围与兼容

实体文字复用手机选中框与三轴代理，射线拖动和数值共用姿态；真实字形最低点包含旋转/厚度/缩放并受固定地面约束。几何就绪按内容键匹配，界面用临时 revision 刷新接地数值；编辑标记不进入成片。

手机围绕最初放置点缩放，移动不重置锚点；缩放编辑写入耦合原生位置与缩放键，保留欧拉多周旋转、所选同刻姿态身份、撤销与旧工程原轨道。五个现有机型分别验证缩放关系和一次撤销，见 [数值记录](browser-verified/scale-anchor-measurements.json)，不等于五机型全部视觉质量已人工通过。

对象时间条融合为整行背景；区间外从运行场景真实 remove，进入/反向定位/导出子采样再 add。文档定义和共享缓存保留，稳定 ID 不随出入场变化。视频有独立显示与播放/暂停区间，画面定格规则、倍速、上层优先和填充共用预览/导出合成；无视频只占一条，分行按交集和稳定层序压缩，关键帧优先命中。

工程版本 4 收集所有片段字节、时序、层级、缩放锚点和实体字形，读取 1/2/3。同一视频按内容哈希共享保存字节，但每段保留独立时钟。旧单视频跟随原对象/作品范围，明确改蓝色端点后才固定；旧循环先保持，只修改填充不改时钟，时序/素材编辑转单次。复制/删除/重绑和恢复不覆盖别的片段。

WASD 平移，↑/↓ 前后，←/→ 围绕构图中心环绕，标准速度约为旧版三倍。录制页等待新画布/素材/字形就绪后启用开始，保留倒计时、对象锁定、回放/采用/撤销。输入框、时间轴、失焦和 Esc 取消有专项证据；显示缩放用 deviceScaleFactor=1.25 检查，不概括为所有操作系统/浏览器缩放组合。

1. tests-first 的默认系统 TEMP 无法重命名，未执行到测试；改用授权工作区的独立临时目录后正常。默认 API/浏览器本机连接受限，保留失败，再在允许本机端口的环境补验通过。没有把这些环境失败写成产品通过。
2. 第二轮构建的未使用声明、后续手柄私有类型访问及测试导入错误已修正。旧版本号、片尾可见性和先位置后缩放的旧期待按新合同调整；原失败日志保留。
3. 原生手柄与 R3F 同时命中导致点轴时选择后方手机；增加事件归属后真实 Z 轴拖动通过。新增手柄按可见性重建使几何每轮增加 9（73→154）；复用/移出恢复/释放后十轮稳定为 74/41。
4. 旧视频迁移写死原长度使作品延长后素材提前退出；增加兼容跟随范围。仅改填充误重置旧循环也已修正并补真实时钟验证。旧回归试验改为先缩放后填精确位置，共享源使用新片段引用；没有声称旧操作顺序完全不变。
5. 早期探针曾在画布未注册时就检查、用错误类型识别手柄、在浏览器 eval 中直接裸导入 three、在作品结束后检查视频时钟；均保留原失败，修正探针后重测。
6. browser-output-first 的资源失败保留；其长片期间有源码修改，Vite 刷新后回到模板页并导致下载等待超时，截图与日志保留，不能算长片通过。固定源码整合 browser-verified 实际完成短片、30 秒和取消重试。
7. 主流程成片后补充焦点检查发现全局已消费 Esc 时，画布仍保留持续键；取消优先停止并屏蔽未释放的重复键。随后 11 项专项及基础检查通过。后续仅修改该键盘交互、旧循环填充及相应单测，另有 4 项旧循环专项与最终 428 项基础检查；采样/编码代码没有再修改。文件差异如实记录，未冒称主流程后所有源码都未变化。
